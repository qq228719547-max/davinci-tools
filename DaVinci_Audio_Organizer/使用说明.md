# 达芬奇音频自动分轨 v1.0

在达芬奇中打开要整理的时间线，运行菜单 **工作区 → 脚本 → Audio_Organizer**。安装后的菜单层级可能包含 Utility。

程序会导出原始 DRT 备份，按分类整理原生片段，再导入一条带 `_Audio_Organized_` 后缀的新时间线，并为片段着色。原时间线和磁盘上的媒体文件保持不变。

| 类别 | 片段颜色 | 默认依据 |
|---|---|---|
| 配音 | 蓝色 | 配音、旁白、voice、narration 等文件夹或文件名 |
| 音乐 | 绿色 | 音乐、配乐、music、bgm 等文件夹或文件名 |
| 音效 | 橙色 | 音效库路径，以及 whoosh、hit、riser、转场等文件名 |
| 同期原声 | 紫色 | MP4、MOV、MXF 等视频文件中的音频 |
| 待确认 | 黄色 | 未命中规则的素材，或跨类别的交叉淡化组 |

## 使用

1. 打开原始、媒体正常在线的时间线。
2. 确认需要整理的音轨处于启用且未锁定状态。
3. 点击 **工作区 → 脚本 → Audio_Organizer**。不要连续重复点击，处理过程中等它完成。
4. 完成后会切换到新时间线。控制台中会输出各轨道名称、片段数量、着色状态及报告位置。
5. 试听转场、配音和音乐入点，查看黄色“待确认”轨。轨道级混音效果应在重新分轨后核对。

如果菜单尚未出现，重启达芬奇。也可以在控制台选择 Lua，运行：

```lua
dofile("C:/Users/1/Documents/Codex/Tools/DaVinci_Audio_Organizer/Audio_Organizer.lua")
```

无需设置外部脚本访问权限，也无需在系统中安装 Python。工具使用本机 Codex 附带的 Python，仅在本地处理文件。

## 保存内容

每次运行会在本工具目录 `runs/日期时间_编号/` 保存：

- `original.drt`：操作前的原生时间线备份。
- `organized.drt`：整理后的原生时间线。
- `report_*.csv`：每个片段的类别、原轨道、精确起止数据和分类依据。
- `report_*.json`：数量、轨道分配、文件哈希及检查结果。
- 出错时的 `*.error.txt`：具体原因。

如果当前轨道不够，脚本会通过达芬奇原生接口建立一条 `_Audio_Prepare_` 副本并增加空轨，然后继续生成最终分轨版。准备副本会保留，方便检查；程序不会自动删除任何时间线。

请保留本工具文件夹的位置。如果移动文件夹，需要修改 `Audio_Organizer.lua` 开头的 `ROOT`。如果更换电脑或 Codex Python 路径变化，需要修改 `PYTHON`。

## 自定义分类

编辑同目录 `rules.json` 即可，下一次运行自动读取。分类优先级为：自定义覆盖规则 → 文件夹规则 → 文件名规则 → 视频同期原声 → 待确认。

例如某段文件虽然放在音效文件夹里，实际是音乐，可以在 `overrides` 中加入：

```json
"overrides": [
  {"category": "music", "patterns": ["我的音乐文件名"]}
]
```

`category` 可填 `voice`、`music`、`sfx`、`original` 或 `review`。`patterns` 使用正则表达式，不区分英文大小写。普通中文名称可以直接填；Windows 路径在 JSON 中需要双反斜杠，建议用文件名或文件夹名匹配。

也可以修改类别的 `color`，使用达芬奇支持的颜色名，例如 Blue、Green、Orange、Purple、Yellow。

## v1 的范围

- 根据路径和文件名分类，不会试听、语音识别或使用 AI 判断声音内容。相机音频统一列入“同期原声”，其中可能含人声。
- 支持全部为 stereo 或全部为 mono 的标准音轨；混合声道格式、多层音频、复杂嵌套序列等会停止并说明原因。
- 相同类别有重叠时保留多条轨道；交叉淡化相连的片段作为整体移动，保持转场连接。
- 片段原始字节、子帧位置、媒体引用、剪辑参数、视频及字幕数据会进行完整性检查。轨道级插件、自动化、总线和混音仍需在新时间线核对。
- DRT 内部结构未公开。用户已确认同类处理方法在当前时间线可用；本工具通用版通过了离线测试和 Lua 模拟测试，但尚未在达芬奇内完成全流程试运行。建议首次先用短时间线测试，后续版本升级达芬奇后也先测试。

## 安装或卸载

把 `Audio_Organizer.lua` 复制到：

```text
C:\Users\1\AppData\Roaming\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility\Audio_Organizer.lua
```

安装只添加这个脚本菜单入口，主体程序保留在当前工具文件夹。卸载时移除菜单入口即可；历史 DRT 备份和报告仍保留。
