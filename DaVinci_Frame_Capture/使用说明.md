# 达芬奇当前帧截图按钮

使用达芬奇原生 `Project:ExportCurrentFrameAsStill` 接口，快捷调用“文件 → 导出 → 将当前帧保存为静帧”。保存的是当前时间线的画面，而非包含软件窗口的屏幕截图。

## 使用

1. 重启达芬奇后，打开 **工作区 → 脚本 → Frame_Capture_Panel**（可能在 Utility 子菜单）。
2. 在悬浮窗里点击“选择文件夹”，指定已有文件夹，也可以直接粘贴文件夹完整路径。
3. 把播放头停到需要的位置，点击 **截图并保存（PNG）**。

窗口置顶，可以在剪辑时保留。文件夹会被记住，以后无需重复选择；每张图片自动命名，包含日期、时间码和序号。窗口底部会显示保存后的完整路径。

默认保存位置：

```text
C:\Users\1\Documents\Codex\Tools\DaVinci_Frame_Capture\Captures
```

## 直接截图菜单

选好保存文件夹后，也可以运行 **工作区 → 脚本 → Frame_Capture_Now**，直接保存当前帧，不打开面板。导出失败时会显示面板和原因。

## 文件

- `Frame_Capture_Panel.lua`：截图悬浮按钮。
- `Frame_Capture_Now.lua`：立即截图菜单。
- `frame_capture_core.lua`：原生导出及自动命名。
- `save_folder.txt`：首次设置后生成，只记录上次选择的保存文件夹。
- `Captures`：默认截图文件夹。

无需 Python、无需网络，不更改时间线或媒体素材。界面通过 Resolve Studio 自带的 UIManager 创建，是独立悬浮窗；没有改写达芬奇原有工具栏。

图片呈现、色彩及叠加元素由达芬奇原生静帧导出决定。应先与菜单中的原生命令对照导出一张，确认符合你的项目需求。
